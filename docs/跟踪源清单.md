> 建立于 2026-09-10（D38）。本文件是 `增量更新工作流.md` S0 步骤的**固定输入**，取代原先散在正文里的散文式列举。

## 0. 用法

1. 按 §1 从 **A 层 → D 层**扫，A 层（聚合 API）优先，因为它是结构化的、能直接 diff；
2. 命中后按 §2 找对应厂商的**官方源**定档（日期、参数、定价必须回官方或 HF 组织页）；
3. 候选落 `temp/d<轮>wave<序>_candidates.jsonl`，字段见 `增量更新工作流.md` §1；
4. 每条候选必须带 `evidence`（URL）。**A 层 API 的 `created` 字段只能当"上架日"用，不能直接当发布日**（铁律见 §4）。

#### A-1 · ModelScope（魔搭）抓取要点（2026-09-13 D44 实测接入）

**结论：魔搭有免鉴权结构化 JSON API，不需要 CDP 爬 DOM**（兄弟工作区 `modelscope_model_update` 的 SKILL 里 DOM 选择器方案可作为兜底，本 API 是首选路径）。

```
# 搜索/列表（PUT，免鉴权；SortBy 合法枚举：Default(实测最新优先) / DownloadsCount / StarsCount / GmtModified）
PUT https://modelscope.cn/api/v1/dolphin/models
body: {"Name":"<org>/","PageSize":100,"PageNumber":1,"SortBy":"Default"}

# 详情（License / Tasks / CreatedTime / ModelInfos.safetensors.model_size / tensor_type / ReadMeContent）
GET https://modelscope.cn/api/v1/models/{org}/{name}

# 仓库文件（max_position_embeddings=上下文长度、n_routed_experts=MoE 判据、quantization_config）
GET https://modelscope.cn/api/v1/models/{org}/{name}/repo?Revision=master&FilePath=config.json
```

**已固化的生产脚本**（dry-run，产物全落 `temp/`，不写主库）：

```bash
PYTHONUTF8=1 python scripts/d44_fetch_modelscope.py               # 全量抓取+比对
PYTHONUTF8=1 python scripts/d44_fetch_modelscope.py --skip-fetch  # 复用快照重新比对
# 产物：d44_modelscope_repos.json（快照）/ d44_msscope_candidates.jsonl（漏采线索，可直喂
# candidate_diff.py）/ d44_msscope_backlog.jsonl（存量未采）/ d44_msscope_fillplan.json（补全候选）
```

D44 首轮实测（22 个官方组织 / 2,979 仓库）：**漏采线索 22 条**（NEW 11 / CHECK_VARIANT 10 / EXISTS 1，如 DeepSeek-V4.1-Flash、Ling-3.0-flash 本体系、MiniCPM5-2B、Nex-N2.5-Max、LongCat-Flash-Lite-Sparse）、**open_weights 空字段命中 66 条，其中 ctx 可补 64 / arch_type 可判 55**（对全库 67 条 open_weights 空.ctx 的覆盖率 95%）。

**用法与红线**：

| 规则 | 说明 |
|---|---|
| **无组织过滤参数** | Owner/Author/Namespace/Publisher 全不生效（实测全站 253,090 不变），只能 `Name="<org>/"` 前缀搜索 + 客户端按 `Path==org` 过滤，否则混入 DevQuasar/mlx-community 等第三方上传 |
| **组织名大小写敏感** | `OpenMOSS` own=0、`openmoss` 命中；白名单维护在脚本顶部 `ORGS`（vendor 写法必须与主库一致） |
| **THUDM/InternLM/NVIDIA 不必挂** | THUDM 模型在 `ZhipuAI` 下、InternLM 在 `Shanghai_AI_Laboratory` 下；NVIDIA 魔搭无官方组织（只有 nv-community 等镜像），继续走 HF |
| **CreatedTime ≠ 发布日** | 是**仓库创建日**（同 HF `createdAt` 性质，§4 铁律适用），只做线索与精化参考，`release_date` 仍回官方公告 |
| **镜像/社区组织不收** | `AI-ModelScope` / `nv-community` / `FlagRelease` 等是镜像或社区机构，不做官方一手 |
| **量化变体不单列** | 名字含 gguf/mlx/awq/gptq/nvfp4 等直接过滤；`-fp8/-fp4` 官方原生按 §3 并入主记录（脚本自动去重） |
| **model_size 是字节数** | 不是参数量（fp8≈1B/byte、bf16≈2B/byte 推导范围仅作量级参考）；`total_params_b` 导入仍回官方声明/README |
| **config.json 的 ctx 是仓库事实** | 线上 API/官方服务可能另有限制或截断，导入须在 notes 标注来源与该限制 |
| **匹配只走 canon 精确匹配** | D40 教训沿用；主库侧索引 `family` / `family-variant` / `full_name` 三个键，同 canon 多仓库时按 variant 风味选代表仓 |

#### C-1 · DataLearner 榜单抓取要点（2026-09-10 D39 实测）

**① 主榜 JSON API（首选，最省事）**

```
https://www.datalearner.com/api/leaderboards/external/text-generation
```
免鉴权直返 JSON：`meta`（`versionTime` / `totalVotes` / `totalModels` / `dataSource`）+ `columns` + `data`（本次 400 行）。
字段：`rank` / `modelName` / `modelCode` / `score`(Elo) / `ci` / `votes` / `organization` / `license` / `thinkingMode`。

> ⚠ 端点**不在页面导航里**，藏在榜单页 `<script type="application/ld+json">` 的 `distribution.contentUrl` 字段。找不到时用这个技巧挖。

**② 分类榜（coding / math）——无独立 API（404），走页面内嵌 flight 流**

Next.js App Router 页面把数据塞在 `self.__next_f.push([1,"…"])` 分片里（本次约 420 块 / 1.1 MB），
需拼接后按括号平衡提取 `"data":[ ... ]`。

**已固化的生产脚本（放 `scripts/`，勿放 `temp/`——temp 会被清理）**：

```bash
# ① 抓榜单 → temp/d39_arena_raw.json（含三榜 rows + 主榜 meta）
python scripts/d39_fetch_arena_leaderboard.py

# ② 导入主库（含三道保守过滤；缺省 dry-run，加 --apply 才写）
```

## 4. 日期口径铁律（2026-09-10 实测得出）

同一模型在不同源的"日期"能差 20 天以上，**必须分清**：

| 日期类型 | 来源 | 能否当 `release_date` |
|---|---|---|
| 官方发布日 | 厂商公告 / 官方台账页 | ✅ 唯一首选 |
| 开源日 | 官方开源公告、HF 组织 | ⚠ 常晚于发布日 |
| HF `createdAt` | HF API | ⚠ 常**早于**发布日（先建库后发布，实测 Qwen3.8-Flash-Next 建库 08-24、发布 08-26） |
| OpenRouter `created` | OpenRouter API | ⚠ 是**上架日**，实测 LongCat-2.0 发布 06-30、OpenRouter 上架 07-20，**滞后 20 天** |
| epoch `Publication date` | epoch CSV | ⚠ 可能是论文/收录日，实测有错值（deepseek-chat 主库 2024-12，epoch 给 2025-12-01） |

**规矩**：`release_date` 只填官方发布日；用其他源推出的必须在该条 `meta.notes` 写明「日期取自 X 源 Y 日，官方发布日待核」。

## 5. 本机环境坑（实测）

- **curl 直连 HTTPS 会失败**：`schannel: CRYPT_E_NO_REVOCATION_CHECK`，HTTP 000。
  解法：加 `--ssl-no-revoke`。例：
  ```bash
  curl -sS --ssl-no-revoke --max-time 60 "https://openrouter.ai/api/v1/models" -o or_models.json
  ```
- **Git Bash 的 `/tmp` 写文件会报 `client returned ERROR on write`**，临时文件落项目 `temp/`。
- `docs.claude.com`、`platform.openai.com` 直连不可达 → 走 WebSearch 摘要 + 红线降级标 T3，不要硬等。
