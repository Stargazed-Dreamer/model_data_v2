4. **合并**（cwd=工作目录，默认 dry-run 先看，确认后再 `--apply`；工具自动生成 .bak）：

```powershell
python scripts/model_data_tool.py merge --file model_data_v2.jsonl `
  --incoming incoming/models/<vendor>__<model>__<variant>.jsonl `
  --on-null take_source --on-both conflict `
  --on-both-override meta.collected_at:source_wins `
  --on-array union_by_key --array-key benchmark config date `
  --array-key-override benchmarks.arena_elo:sub_benchmark,date `
  --on-schema upgrade --apply
```

新条目（本批全是 to_add 新增）无冲突侧，merge 会自动 normalize_record 补全骨架。
